AFTER THE THRESHOLD

CHAPTER ONE: THE BASEMENT

STORY:
  You wake up in a dark forest with no memory. Cold and alone in a storm, you find a house. Inside, the air feels wrong.
  Reality begins to distort. When you try to leave, the door won't open. The house holds secrets. You are trapped.

ABOUT THE PROJECT:
  After The Threshold is a 3D psychological horror game developed in Godot Engine. Navigate an unsettling atmospheric environment,
  interact with strange mechanics, and uncover the truth hidden inside the house.

Engine: Godot Engine 4

Genre: Atmospheric Horror / Puzzle / Narrative

Platform: Linux

HOW TO RUN:
  Visit my itch.io page and download the game files by following the instructions there:
  https://mono19189.itch.io/after-the-threshold
